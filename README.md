# ビジネスロープレ - 実践トレーニングアプリ

ビジネスシーンでの対話スキルを練習できるWebアプリケーションです。

## 機能

- **シナリオ選択**: 3つのビジネスシナリオから選んで練習
  - 新規営業（初回訪問）
  - クレーム対応（商品不具合）
  - 電話応対（取り次ぎ）
- **チャット形式の会話**: リアルなビジネスシーンをチャット形式で体験
- **選択肢方式**: 3つの選択肢から最適な対応を選択
- **リアルタイムフィードバック**: 各選択に対するアドバイスを即座に表示
- **スコアリング**: 対応力をスコアとランクで評価

## 使い方

1. `index.html` をブラウザで開く（ダブルクリック）
2. シナリオカードを選択してロープレ開始
3. 相手の発言に対して最適な選択肢を選ぶ
4. 全ステップ完了後、スコアとフィードバックを確認

## ファイル構成

```
開発/
├── index.html          # メインHTMLファイル
├── README.md           # このファイル
├── css/
│   └── styles.css      # スタイルシート
└── js/
    ├── app.js          # アプリケーションロジック
    └── scenarios.js    # シナリオデータ
```

## 技術仕様

- **HTML5 / CSS3 / JavaScript（ES6）**
- サーバー不要（ローカルで動作）
- レスポンシブ対応（スマートフォン・タブレット対応）
- 外部ライブラリ不要（Google Fontsのみ使用）

## シナリオの追加方法

`js/scenarios.js` にシナリオデータを追加することで、新しいシナリオを作成できます。
詳しいデータ構造はファイル冒頭のコメントを参照してください。
